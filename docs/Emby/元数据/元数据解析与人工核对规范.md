# Emby 元数据解析与人工核对规范

## 搜索与数据源匹配

- 日语/韩语媒体库默认使用 `hunk-ch`。
- 番号以 `GV-` 开头时，搜索请求自动去掉前缀，例如 `GV-OAV1350` 的搜索词是 `OAV1350`。
- 详情页的 `source_id` 保留原始站内编号，产品番号、显示标题前缀和 `ProviderIds.product_number` 使用去掉 `GV-` 的番号。
- 用户手动选择其它数据源但输入仍为 `GV-` 番号时，后端自动切换到 `hunk-ch`。

## 字段回报

抓取详情后，右侧“解析结果回报（请逐项核对）”逐字段展示解析器实际产出的值。空值显示为 `—`，列表和对象以 JSON 展示；这不是系统推测值。

写入前重点核对名称、原标题、产品番号、上映日期、简介、工作室、演员、标签、封面和外部 ID。错误时直接编辑候选值，或取消对应写入字段。

## Genre 规则

Genre/类型默认不解析、不写入。数据源分类词可能是筛选标签或营销标签，不能直接视为 Emby 类型；确需使用时人工补充后再勾选写入。

## 页面规则

搜索结果采用网站商品搜索风格展示图片、标题、价格、发布日期、状态标签和操作。搜索期间不在“待处理列表”上方插入提示栏，避免列表位置跳动。
