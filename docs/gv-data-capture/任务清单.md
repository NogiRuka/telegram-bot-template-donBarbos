## H. 测试与验证

离线验证保存的页面结构：

```powershell
python -m unittest bot.tests.test_emby_metadata -v
```

IDEA 或命令行验证真实关键词（使用本地 `bot/config/cookies.toml`）：

```powershell
python -m bot.tools.inspect_emby_metadata CO-LV00070 --limit 10
```

命令会打印候选数量和每个候选的完整 JSON。候选数量为 1 时标记为“唯一匹配”，此时重点人工核对 `title`、`original_title`、`overview`、`release_date`、`genres`、`studios`、`people`、`tags`、`poster_url`。
