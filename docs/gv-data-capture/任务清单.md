# Emby 元数据管理工具任务清单

状态说明：当前阶段已实现后端基础 API，默认使用模拟 Item 数据；前端和外部数据源暂不实现。

- [ ] 确认 Emby 版本和 API 权限。
- [ ] 确认 Emby 公网访问地址、HTTPS 和访问控制方式。
- [ ] 确认计划使用的数据源及其授权、robots、频率限制和登录要求。
- [ ] 确认第一阶段只处理电影，不处理剧集层级。
- [ ] 确认元数据覆盖策略：仅填空字段或允许覆盖。
