# 项目文档导航

本文档目录按“项目级资料、功能设计、Emby 专题、外部集成、历史归档”组织。新增文档应优先放入已有专题，避免再次堆放到 `docs/` 根目录。

## 项目

- `项目/开发规范/`：开发流程、注释规范、MarkdownV2 等编码与协作约定。
- `项目/架构/`：项目结构、数据库设计和结构治理分析。
- `项目/规划/`：项目治理清单、原始待办与跨功能开发计划；本轮设计入口见 [`未完成功能总体设计`](项目/规划/未完成功能总体设计.md)。

## 功能设计

- `功能设计/红包/`：红包业务草案、素材合成需求和性能优化记录。
- `功能设计/注册与保号/`：注册增强旧草案；当前跨功能方案统一收录在项目规划中。
- `功能设计/经济系统/`：精粹、签到和经济系统设计。
- `功能设计/主消息与主图/`：主消息交互与主图管理。
- `功能设计/问答/`：问答系统设计。
- `功能设计/通知/`：新增节目等通知能力；Android 个人通知客户端见 [`桜色男孩 Android App 开发交接文档`](功能设计/通知/桜色男孩安卓App开发交接文档.md)。
- `功能设计/群组消息/`：群组消息保存与使用说明。
- `功能设计/命令系统/`：现有斜杠命令、角色权限、用户界面与优化审查。
  - `命令维护进度.md`：记录命令改造状态、行为边界、部署清单与待讨论决策。
- `功能设计/权限/`：机器人权限模型。

## Emby

- `Emby/账号/`：Emby 用户同步与更新逻辑。
- `Emby/元数据/`：元数据解析、人工核对和 gv-data-capture 工作台。
- `Emby/API参考/`：从 Emby API 调试过程保留下来的接口片段。这里只能使用占位凭据，不得写入真实 Token。

## 外部集成

- `集成/OpenAI/`：OpenAI API 参考资料。
- `集成/xAI/`：xAI 翻译服务改造需求。

## 归档

- `归档/原始资料/`：历史对话、混合草稿等仅供追溯的资料，不作为当前实现依据。

## 文档状态约定

- `当前设计`：已根据当前代码核对，可作为下一轮开发评审依据。
- `草案`：尚未确认全部业务规则，不应直接据此实现。
- `实现详解`：描述已经存在的实现，但仍需以当前代码为准。
- `原始资料`：只保留历史背景，不作为需求真相源。
